Temple Album – Website Plan

Site Name

Temple Album

Temple Album is a website dedicated to showcasing LDS temples around the world. The name was chosen because it reflects a visual and informational collection that users can explore like a digital album.

Optional domain: temple-album.org

Site Purpose

The purpose of the Temple Album website is to provide users with an organized, visually appealing collection of LDS temples. Visitors can browse temples, filter them by characteristics such as age or size, and learn basic historical details about each temple.

Scenarios

  • Which temples were dedicated before 1900?
  • How can I filter temples to see only large or recently built ones?
